# Next blocker

The outside-root tail is formalized and one exact source tail terminal is kernel-checked.
The first unresolved formalization step is not the affine tail: it is a source-matched
quadratic leaf.

The next pilot must encode one actual V2 quadratic leaf's five anchor codes, its exact
dyadic box and the 15 selected source models. It must then prove that the upstream Lean
catalog entries and the V2 JSON `stable_piece_index` ownership semantics select those same
models, and that the resulting exact tangent checker accepts the leaf. The current
catalog comparison verifies field equality but does not prove ownership/selection in Lean.

After that, full A1294 requires a chunked encoding of the 13,454,121 topology tokens,
6,727,061 terminal kinds, and 6,725,258 five-coordinate anchor payloads, plus a kernel
proof that every stream is consumed exactly and every terminal check passes. The full
source-free Python replay is included as external evidence only; this pilot does not promote
it to a kernel proof.

The successful upstream AffineTree build required 5.56 GB peak RSS; the A1290 certificate
target expanded to 55,731 jobs and was stopped. Therefore a full Lean port is resource-
uncertain. A chunked quadratic-leaf pilot and resource benchmark are the justified next
step; the complete 13.45-million-node port is not yet justified.
