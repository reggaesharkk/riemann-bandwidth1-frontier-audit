## 1. Generic Gaussian Loewner direction

Let a and h be real random grid vectors and write the Hermitian
Loewner/Calderon matrix as

    W
      = M_h + [M_a,J],

where

    J_ij=1/[pi(j-i)], i!=j,
    J_ii=0.

For the WP84 circular field,

    a=Im Z,

    h=2 Re Z - 2 Im Z'/L.

Define the three deterministic covariance matrices

    A = E[a a^T],

    H = E[h h^T],

    C = E[h a^T].

Then

    E[a h^T]=C^T.

## 2. Diagonal-diagonal term

For every deterministic matrix X,

    E[
      M_h X M_h

      =
      boxed:
      H o X,

where o denotes the Hadamard product.

## 3. The two cross terms

Using

    [M_a,J]=M_a J-JM_a,

one gets exactly

    E[
      M_h X [M_a,J]
    ]

      =
      boxed:
      (C o X)J
      - C o (XJ),

and

    E[
      [M_a,J] X M_h
    ]

      =
      boxed:
      C^T o (JX)
      - J(C^T o X).

## 4. Commutator-commutator term

Expanding the four products gives

    E[
      [M_a,J] X [M_a,J]
    ]

      =
      boxed:
        (A o (JX))J
        - A o (JXJ)
        - J(A o X)J
        + J(A o (XJ)).

## 5. Exact covariance map

Combining Sections 2--4,

    boxed:
    V(X)

      H o X

There is no random variable and no prime index left in V once A,H,C are
