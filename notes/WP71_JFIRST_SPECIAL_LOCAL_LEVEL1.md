# WP71 — special-prime level-1 local table for the j-first four-point model\n\nDate: 2026-10-04\nStatus: **LEVEL-p SPECIAL OUTER PATTERNS CLOSED; HIGHER p-ADIC VALUATIONS STILL OPEN**\n\nThe generic-prime audit covered p not dividing b1*b2. This note handles the residue-level cases where p divides one or both outer coefficients.\n\nUse the same one-lock normalization\n\n    p*(1-1/p)^4.\n\n## 1. p divides exactly one of b1,b2\n\nAssume p|b1 and p does not divide b2. Then locally\n\n    b1*n-b2*m=j\n\nfixes m from j, while n remains free. Also r=b1/g is divisible by p, so m-rk=m mod p, while q is a p-unit.\n\nHence:\n\n- if j=0: no admissible m, so N=0;\n- if j is nonzero and k=0: N=p-1;\n- if j and k are both nonzero: N=p-2.\n\nThe same table holds with b1,b2 reversed.\n\nAveraging over all (k,j) mod p gives the exact normalized local factor\n\n    boxed: p/(p-1).\n\n## 2. p divides both b1 and b2 at level 1\n\nAt the first residue level the lock equation forces j=0 mod p.\n\n- j nonzero: N=0;\n- j=0,k=0: N=(p-1)^2;\n- j=0,k nonzero: N=(p-2)^2.\n\nUnder the same one-lock average this gives\n\n    p(p^2-3p+3)/(p-1)^3\n      = 1 + 1/(p-1)^3,\n\nthe same averaged factor as the generic four-point parallelogram.\n\n## 3. Interpretation\n\nThese tables show that primes dividing exactly one outer leg carry a genuine local correction p/(p-1). That correction must be present in the singular-series main; it cannot be recovered from the generic-prime Euler factor alone.\n\nWhen p divides both outer legs, higher valuations of b1,b2 and j matter. The level-p table is therefore not the full p-adic answer.
