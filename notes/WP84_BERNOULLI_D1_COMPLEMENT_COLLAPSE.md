Status: **EXACT — THE ENTIRE FIRST-ORDER CURRENT-PRIME SUM COLLAPSES TO ONE REMAINING-OPERATOR DIRICHLET FIELD**

No percentage theorem is claimed here.

The Bernoulli representation still appears to contain a sum over every
possible current prime base p.  For the first-order term that sum is
unnecessary because D1 is linear in the current block.

## 1. Full Bernoulli state

Let

    H_t
      = S + sum_p xi_p(t) G_p,

with independent xi_p~Bernoulli(t), and write

    R_t=(H_t-zI)^(-1).

Define the selected and remaining prime operators

    P_sel(t)=sum_p xi_p G_p,

    P_rem(t)=sum_p (1-xi_p) G_p.

Thus

    H_t=S+P_sel,

and

    P_full=P_sel+P_rem.

At the scalar Dirichlet-polynomial level,

    Q_sel(tau)=sum_p xi_p Q_p(tau),

    Q_rem(tau)=Q_full(tau)-Q_sel(tau).

## 2. Coupling the leave-one-out state

For fixed p, the state in the exact Bernoulliized permutation formula excludes
p.

Under the full Bernoulli mask, conditioning on xi_p=0 gives exactly that
leave-one-out law.

Therefore, for every current-linear functional L(H;G_p),

    E_{-p} L(H_{-p};G_p)

equals

    (1/(1-t))
      E[
        (1-xi_p)
        L(H_t;G_p)
      ].

## 3. Sum every possible current block

The D1 primitive is

    tau(G_p R_t),

and its z derivative gives the first Lindeberg coefficient.

Because both tau(G_p R_t) and tau(R_t G_p R_t) are linear in G_p,

    sum_p (1-xi_p) tau(G_p R_t)

      = tau(P_rem R_t),

and

    sum_p (1-xi_p) tau(R_t G_p R_t)

      = tau(R_t P_rem R_t).

Hence the exact first-order permutation average becomes

    boxed:
    A1(z)
      =
      int_0^1
        (1/(1-t))
        E[
          tau(R_t P_rem(t) R_t)
        ] dt.

No explicit current-prime sum remains.

## 4. One scalar field instead of all current Q_p

The remaining operator P_rem is itself a sharp Loewner operator generated by

    boxed:
    Q_rem
      = Q_full-Q_sel.

Thus the rank-three/scalar D1 formula can be used once with

    state field:
      a=Im Q_sel,

    current/complement field:
      alpha=Im Q_rem,

rather than once for every p.

Explicitly,

    tau(P_rem R_t)

      = d^(-1)[
          sum_i beta_rem,i (R_t)_ii
          +(2/pi^2)
            u_t^T L_{alpha_rem} v_t
        ],

where

    u_t=R_t 1,
    v_t=R_t Im Q_sel.

This is an exact finite-d identity.

## 5. Selected and remaining fields are one centered fluctuation

Write

    Z_t(tau)
      = sum_p (xi_p-t) Q_p(tau).

Then

    Q_sel
      = t Q_full + Z_t,

    boxed:
    Q_rem
      = (1-t) Q_full - Z_t.

So the selected and remaining Dirichlet fields are not two independent
objects.  They are deterministic complementary means plus **one** centered
random scalar field.

Their covariance is therefore automatically anti-correlated.

This is the smallest stochastic state for the Bernoulli D1 route.

## 6. Background scalarization makes part of the drift explicit

Because

    P_rem=P_full-(H_t-S),

the D1 integrand may also be written

    tau(R_t P_full R_t)
      - tau(R_t(H_t-S)R_t).

If the source-closed background replacement S=s0 I+o is inserted, then

    R_t(H_t-s0 I)R_t

Thus, modulo the already-controlled background error,

    boxed:
    tau(R_t P_rem R_t)

      tau(R_t P_full R_t)

The only genuinely arithmetic part left in this form is the total-prime
direction

    tau(R_t P_full R_t).

The other two terms are the normalized resolvent and its z derivative.
