# WP84 — exact modulated-Toeplitz block norm and infinitesimal prime array\n\nDate: 2026-10-04\nStatus: **BLOCK OPERATOR-NORM BOUND CLOSED; SQUARE/CUBE MASS LEDGER CLOSED; RESOLVENT FIRST/SECOND-ORDER ASSEMBLY OPEN**\n\nThis note upgrades the structured prime decomposition in `WP84_BOUNDED_RESOLVENT_CONSUMER.md` from an entry formula to an operator-norm statement.\n\n## 1. Toeplitz overlap block\n\nFor fixed `y` define\n\n    f_y(x)=phi(x-y/2) phi(x+y/2).\n\nSince `0<=phi<=1`,\n\n    0<=f_y<=1.\n\nThe complexified cosine block has the form\n\n    C^+(y)=(2pi/L) D_y T_y D_y,\n\nwhere `D_y` is diagonal unitary and\n\n    (T_y)_{kl}=A_{k-l}(y),\n\n    A_r(y)=integral f_y(x) exp(-i r h x) dx,\n\nwith `h=2pi/L`.\n\n## 2. Exact finite-section operator norm\n\nFor any coefficient vector `c=(c_0,...,c_{d-1})`,\n\n    c^* T_y c\n      = integral f_y(x)\n          |sum_k c_k exp(i k h x)|^2 dx.\n\nThe support of `f_y` lies in an interval of length at most L. Enlarge to any interval of length exactly L. On such an interval the exponentials\n\n    exp(i k 2pi x/L)\n\nare orthogonal, so\n\n    integral_interval |sum_k c_k exp(i k h x)|^2 dx\n      = L sum_k |c_k|^2.\n\nBecause `0<=f_y<=1`,\n\n    boxed:\n    0 <= T_y <= L I\n\nin quadratic-form order, and therefore\n\n    boxed:\n    ||T_y||_op <= L.\n\nSince `D_y` is unitary,\n\n    ||C^+(y)||_op <= 2pi.\n\nThe real cosine block is\n\n    C(y)=(C^+(y)+C^+(-y))/2,\n\nhence\n\n    boxed:\n    ||C(y)||_op <= 2pi.\n\nNo asymptotics and no zero information enter this estimate.\n\n## 3. One prime-power block in hat units\n\nWrite\n\n    a_n=Lambda(n)/sqrt(n).\n\nThe prime density is\n\n    P_X(tau)=-(1/pi) sum_{n<=X} a_n cos(tau log n).\n\nSo in tilde units the n-th prime-power matrix block is\n\n    B_n^tilde=-(a_n/pi) C(log n),\n\nand\n\n    ||B_n^tilde||_op <= 2 a_n.\n\nHat units divide tilde units by `a L`. The source-closed taper theorem gives `a>=1/2`. Therefore\n\n    boxed:\n    ||B_n^hat||_op\n      <= 2 a_n/(a L)\n      <= 4 Lambda(n)/(L sqrt(n)).\n\nIn particular every individual prime-power block is infinitesimal:\n\n    max_{n>=2} ||B_n^hat||_op = O(1/L).\n\n## 4. Square mass is finite\n\nSquaring and summing gives\n\n    sum_{n<=X} ||B_n^hat||_op^2\n      <= 16/L^2 * sum_{n<=X} Lambda(n)^2/n.\n\nThe source-closed Chebyshev--Mertens input is\n\n    sum_{n<=X} Lambda(n)^2/n\n      = L^2/2 + O(L)\n\nfor `X=e^L`. Hence\n\n    boxed:\n    sum ||B_n^hat||_op^2 <= 8+O(1/L).\n\n## 5. Cubic mass vanishes\n\nLikewise\n\n    sum_{n<=X} ||B_n^hat||_op^3\n      <= 64/L^3\n         * sum_{n<=X} Lambda(n)^3/n^(3/2).\n\nUsing only `Lambda(n)<=log n`, the infinite series converges. A dyadic proof is elementary: on\n\n    2^k <= n < 2^(k+1)\n\nthe whole shell is at most\n\n    ((k+1)log2)^3 2^(-k/2),\n\nwhose sum converges.\n\nTherefore\n\n    boxed:\n    sum_{n<=X} ||B_n^hat||_op^3 = O(L^-3)=o(1).\n\nThis is much stronger than merely saying each block is small.\n\n## 6. Exact resolvent telescoping consequence\n\nLet\n\n    H_j=S+B_1+...+B_j,\n    R_j(z)=(H_j-zI)^(-1),\n\nwith `Im z=1`; then `||R_j(z)||<=1` for every Hermitian `H_j`.\n\nFor one update `H+B`, the resolvent identity iterated three times gives exactly\n\n    R_{H+B}\n      =R_H\n       -R_H B R_H\n       +R_H B R_H B R_H\n       -R_H B R_H B R_H B R_{H+B}.\n\nHence the normalized-trace cubic remainder obeys\n\n    |d^-1 tr(remainder)| <= ||B||^3.\n\nSumming over every prime-power block yields total normalized cubic remainder\n\n    boxed:\n    O(L^-3)=o(1).\n\nSo the fixed-pole resolvent is, rigorously, a **second-order infinitesimal-array problem**.\n\n## 7. The new narrow obstruction\n\nThe nonlinear difficulty has been reduced to the accumulated first- and second-order terms\n\n    - d^-1 tr(R_{j-1} B_j R_{j-1})\n\nand\n\n    + d^-1 tr(R_{j-1} B_j R_{j-1} B_j R_{j-1}),\n\nwhere the background resolvent evolves with j.\n\nThe cubic and higher Taylor debt is already o(1).\n\nThe next theorem must exploit the arithmetic phases / modulated-Toeplitz structure to evaluate or close these first two orders without reverting to raw fourth/eighth moments.\n\nCompanion ledger:\n\n    `src/wp84_infinitesimal_prime_blocks.py`.\n
