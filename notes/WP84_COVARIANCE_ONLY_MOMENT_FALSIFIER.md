# WP84 — moment-consistency falsifier for the covariance-only multiplication closure

Date: 2026-10-05

Status: **PURE MULTIPLICATION / ZERO-DRIFT ALG-star IS INCOMPATIBLE WITH THE CURRENT SIX-MOMENT BULK MODEL STARTING AT ORDER FOUR**

The sharp multiplication-resolvent notes identify a tempting closure: scalar background, zero first-order drift, and only the mixed covariance kernel

    (K a)(x)=integral_0^1 |x-u| a(u) du.

If that were the complete limiting algebra, the centered bulk law would be the operator-valued semicircular law generated by K.

This note checks that proposal against the exact model moments already used by the conditional Christoffel consumer.

## 1. First three moments agree

Put Y=X-1.  The covariance-only model has

    E[Y]=0,
    E[Y^2]=int_0^1 (K1)(x) dx = 1/3,
    E[Y^3]=0.

Therefore

    m1=1,
    m2=1+1/3=4/3,
    m3=1+3*(1/3)=2.

These match the current model exactly.

## 2. The first discrepancy is m4

Here

    (K1)(x)=x^2-x+1/2.

For the operator-valued semicircular covariance closure,

    E[Y^4]=2*integral_0^1 (K1)(x)^2 dx
          = 2*(7/60)
          = 7/30.

Hence the predicted raw fourth moment is

    m4_cov = 1 + 6*(1/3) + 7/30
           = 97/30.

The current exact six-moment model uses

    m4_target = 13/4.

The deficit is exactly

    boxed: 13/4 - 97/30 = 1/60.

So the covariance-only multiplication closure reproduces m1,m2,m3 and then misses the first higher-even rung by a nonzero leading constant.

## 3. The fifth centered moment gives an independent mismatch

The centered covariance-only semicircular law has all odd centered moments zero.

But the current six-moment model gives

    E[(X-1)^5] = 1/36.

Thus a leading non-symmetric/non-multiplication correction survives in the target bulk model.

## 4. Interpretation

This is not a contradiction in the repository.  It is a falsifier for a particular closure ansatz.

The exact Lindeberg cube-mass estimate only removes cubic-and-higher **single-block Taylor remainders**.  It does not imply that repeated second-order interactions keep the evolving resolvent inside the multiplication algebra.

The missing 1/60 at m4 is therefore a quantitative witness of the noncommutative leakage ignored by pure ALG-star.

That observation also explains why the first disagreement appears precisely at the fourth-moment tier.

## 5. Consequence for the resolvent route

The statement

    'intermediate resolvents are asymptotically multiplication operators'

is too strong if the desired bounded bulk law is the present six-moment model.

A viable fixed-circle theory must retain at least one additional operator channel beyond the multiplication symbol.  Candidates are:

- a Toeplitz/translation channel carried by the same-sign branch;
- a two-component matrix-valued Dyson closure;
- an exact truncated-Wiener-Hopf functional calculus that never scalarizes the resolvent.
