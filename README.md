# Riemann bandwidth-one frontier audit

A proof earns trust one bridge at a time. This repository keeps the source, certificates, and hostile checks for a research program exploring bandwidth-one Weil-form methods and simple zeros of the Riemann zeta function.

## What the evidence supports

The repository contains finite certificates, selected Lean kernel proofs, exact-arithmetic replays, and exploratory computations. Each result is limited to the proposition and hypotheses actually checked. A source hash identifies bytes; it does not prove the mathematics. A successful script replay is not a Lean kernel proof, and a verified local lemma does not by itself establish a global theorem.

The complete A1294 root predicate remains open. The WP84 ordinary-prime connected aggregate and the strict greater-than-79% claim remain open. No Riemann Hypothesis proof is claimed here.

## Working principle

We keep the claim boundary visible: preserve what has been checked, name what remains unproved, and let each broader conclusion wait for its own complete argument.
